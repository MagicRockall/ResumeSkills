# Reference List Builder

## When to Use This Skill

Use when user needs to create a reference list, choose references, or prepare for reference checks. Mentions: "references", "reference list", "professional references".

## Reference Hierarchy

1. Recent direct supervisor (most valuable)
2. Senior leaders who know your work
3. Peers and cross-functional partners
4. Clients, vendors, professors
5. Avoid: friends, family, HR-only contacts

## Reference List Format

```
PROFESSIONAL REFERENCES

Jane Smith
Senior Director of Product | TechCorp Inc.
Phone: (555) 123-4567 | Email: jane@techcorp.com
Relationship: Direct supervisor for 3 years (2020-2023)
```

## Reference Preparation Steps

1. Ask permission before listing anyone
2. Send them: your resume, job description, key talking points, specific projects to mention
3. Follow up after reference check to thank them

## Key Checklist

- ✅ Have 3-5 references ready
- ✅ All have given permission
- ✅ Contact info is current and accurate
- ✅ Each reference knows about the specific role
- ✅ At least one direct supervisor included
- ✅ References are enthusiastic (not just willing)
- ✅ Don't include with initial application (unless requested)
