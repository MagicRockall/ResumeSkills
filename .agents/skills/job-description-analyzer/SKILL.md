# Job Description Analyzer

## When to Use This Skill

Use when the user wants to analyze a job posting, asks "should I apply?", wants a match percentage, or mentions: "analyze this job", "am I qualified", "match score".

## Match Score Interpretation

- 90-100%: Overqualified
- 75-89%: Excellent fit — apply immediately
- 60-74%: Good fit — apply with strong cover letter
- 50-59%: Stretch role
- <50%: Under-qualified

## Analysis Output

Provide: Overall Match Score, Requirements Breakdown, Strengths to Emphasize, Gaps + strategies, Resume Customization Strategy, Cover Letter Talking Points, Red Flags, Application Timeline.

## Red Flags

Workload: "Wear many hats", "Fast-paced", "Hit the ground running"
Culture: "Rockstar/Ninja", "Like a family", "Unlimited vacation"
Comp: No salary range, "Equity-heavy", commission-only
