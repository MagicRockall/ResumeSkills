# Salary Negotiation Prep

## When to Use This Skill

Use when user wants to negotiate an offer, research market rates, or create a counter-offer. Mentions: "salary negotiation", "counter offer", "how much should I ask for".

## Key Principle

84% of employers expect candidates to negotiate. Not negotiating leaves $500K-$1M on career table.

## Counter-Offer Framework

1. Express enthusiasm for the role
2. Reinforce your value
3. Make specific ask with justification
4. Open to discussion

## Negotiation Tactics

**DO:** Always negotiate, research thoroughly, be specific with numbers, consider total comp
**DON'T:** Accept on the spot, lie about competing offers, make ultimatums

## Total Compensation Components

Base + Signing Bonus + Annual Bonus + Equity (RSUs/Options) + 401k Match + Benefits + Perks

## If Base Won't Move, Negotiate

- Signing bonus (one-time, easier to approve)
- Additional equity
- Earlier performance review
- More vacation days
- Remote flexibility
- Professional development budget
