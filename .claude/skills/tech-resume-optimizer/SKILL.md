# Tech Resume Optimizer

## When to Use This Skill

Use when user is applying for SWE, PM, data, or technical roles. Mentions: "tech resume", "software engineer resume", "developer resume".

## Tech Resume Structure

1. Contact (GitHub, Portfolio, LinkedIn)
2. Technical Skills (critical for ATS)
3. Work Experience
4. Projects (especially for early career)
5. Education
6. Certifications

## Technical Skills Organization

```
Languages: Python, JavaScript, TypeScript, SQL
Frameworks: React, Node.js, Django
Databases: PostgreSQL, MongoDB, Redis
Cloud/Infra: AWS (EC2, S3, Lambda), Docker, Kubernetes
Tools: Git, JIRA, CI/CD
```

## Technical Bullet Formula

**[Action Verb] + [Technical What] + [Scale/Impact] + [Technology Used]**

❌ "Worked on backend services"
✅ "Architected microservices migration reducing deployment time from 2 hours to 15 minutes"

## Technical Metrics

- Scale: "serving 500K DAU", "handling 10K req/sec"
- Performance: "reduced latency from 500ms to 200ms"
- Efficiency: "reduced AWS costs by 40% ($200K annually)"
- Business: "features drove $XM revenue"
