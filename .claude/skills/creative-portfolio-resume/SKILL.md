# Creative Portfolio Resume

## When to Use This Skill

Use when user works in a creative field (design, marketing, writing) and needs to balance visual design with ATS. Mentions: "creative resume", "designer resume", "portfolio resume".

## Two-Version Strategy

**Version 1 (ATS-Compatible):** For online portals, job boards, any online submission
**Version 2 (Designed):** For networking events, direct email, portfolio website, creative agencies

## Safe Creative Touches (ATS Version)

- ✅ Custom ATS-safe font (Arial, Calibri, Helvetica)
- ✅ Strategic bold and italic
- ✅ Simple section dividers (single line)
- ✅ Sparing color in name/headers
- ✅ Hyperlinks to portfolio
- ❌ Still avoid: columns, text boxes, images, tables for layout

## Designed Version Principles

1. Your resume IS a design sample — make it count
2. Clarity over cleverness — information must be findable
3. Brand consistency — match your portfolio website
4. Limited palette: 2-3 colors max, must print well in B&W

## Portfolio Integration

Always include portfolio link prominently. For case studies, link directly from relevant bullets:
"Redesigned checkout flow, increasing conversion 40% — Case Study: yourname.com/checkout"
